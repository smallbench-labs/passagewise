# 外掛名稱候選（2026-11-19 查證）

原則：名稱不用 Kindle、Kobo、KOReader、Amazon、Apple Books 等商標。Roger 於 2026-11-19 11:33（台北時間）選定 **Passagewise**（id `passagewise`）。程式與 manifest 已改名。

查證範圍：`cycle2/plugins.json`（2026-11-19 10:04，10,570 個外掛）的 id 與 name、npm registry、GitHub 倉庫名稱搜尋。沒有逐一查網域註冊，下面有寫到已知的網站。

## 建議的三個

### 1. Passagewise（建議首選）

- 意思：一段段的書摘。
- 與 Docxwise、Streakwise 的 -wise 系列一致。
- Obsidian 外掛目錄：沒有同名。
- npm：`passagewise` 回 404。
- GitHub：`passagewise` / `passage-wise` 搜尋總數 0。

### 2. Highlightwise

- 意思：功能一眼就懂。
- Obsidian、npm、GitHub 倉庫名稱搜尋都沒有叫這個名字的項目。
- 缺點：比較長；目錄裡已經有大量名稱含 “Highlight” 的外掛（PDF、語法顯色等），雖然不是同名，比較不容易從名單裡跳出來。

### 3. Bindwise

- 意思：書的裝訂／把劃線裝成筆記。
- Obsidian、npm、GitHub 倉庫名稱搜尋都沒有叫這個名字的項目。
- 缺點：比前兩個不好懂，可能被聽成 software binding。

## 看過但沒列入前三的

| 名稱 | 原因 |
|---|---|
| Clipwise | npm 已有 `clipwise`（螢幕錄製工具，https://www.npmjs.com/package/clipwise）；GitHub 搜尋到 155 個倉庫；另有瀏覽器套件 https://clipwise-app.github.io/ |
| Quotewise | GitHub 有多個 QuoteWise 專案；另有 https://quotewise.io/ |
| Inkwise | GitHub 搜尋 41 個，含中文寫作軟體「InkWise 墨智」 |

| Markwise | npm 已有 `markwise` |
| Spinewise | GitHub 有 4 個無關專案（其中一個是智慧椅子） |
| Gleamwise | npm、GitHub 都沒有，但語意較隱 |
